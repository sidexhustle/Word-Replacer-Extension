Rules

Matching ignores case; the replacement is shown exactly as typed. Anywhere (default): also inside other words. Word + endings: only where a word starts. Whole word: only the exact word. Longer rules win when rules overlap. The example rules are switched off: tick one to try it, or delete them.

Where to replace

Never changed: text you type in inputs/text areas, rich-text editors (Gmail compose, Notion, Jira…), scripts and styles — so nothing you write or save is altered.

Disabled sites

    Works on every website.

    A site added here is skipped together with its sub-sites (example.com also covers www.example.com). Quicker ways to switch a site off or on: the ⇄ toolbar button (Active on …), or right-click any page → Word Replacer: turn off/on for this site.

    Backup & other computers

    Each computer keeps its own list of words. To copy them: click Export here, then Import file… on the other computer. Tip: put the exported file into the extension folder as rules.json, and new installs will start with these words.
